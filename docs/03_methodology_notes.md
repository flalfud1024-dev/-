# 방법론 상세 노트

## 바이브 코딩 vs 논문용 파이프라인

| 구분 | 바이브 코딩 | 논문용 파이프라인 |
|------|-------------|-------------------|
| 목적 | 빠른 결과 | 재현 가능한 분석 |
| 코드 이해 | 불필요 | 필수 (심사 질문 대비) |
| 랜덤 시드 | 미설정 | 고정 필수 (random_state=42) |
| 버전 관리 | 없음 | requirements.txt 명시 |
| 논문 부록 | 해당 없음 | 전체 코드 첨부 |
| 재현성 | 불가 | 타 연구자 동일 결과 도출 가능 |

**결론**: 바이브 코딩으로 아이디어를 탐색하고, 그 결과를 **재현 가능한 코드로 정제**하는 것이 박사논문의 올바른 접근.

6. **데이터**: 부록 5에 수집 현황 명시 (익명화 처리, 더우반 이용약관 준수 여부)

## 예상 심사 질문 대응 노트

심사위원이 물을 수 있는 질문 + 대응 방향:

### Q1. "LDA에서 토픽 수를 왜 이 숫자로 결정하셨나요?"
**A.** 코히런스 스코어(c_v)를 k=3~8 구간에서 계산하여 최대값을 선택. c_v는 인간 평가자와의 상관관계가 가장 높은 지표로 알려져 있음(Röder et al., 2015).

### Q2. "c_v 말고 다른 지표는 왜 안 쓰셨나요?"
**A.** u_mass, c_uci, c_npmi도 검토했으나 c_v가 단어 공출현 창(sliding window)과 NPMI 기반으로 인간 해석과의 정합성이 높아 채택.

### Q3. "Mann-Whitney U를 쓴 이유가 뭔가요? t-검정은 왜 안 되나요?"
**A.** Shapiro-Wilk 정규성 검정 결과 감성 점수가 정규분포를 따르지 않음(p < 0.05). 따라서 비모수 검정인 Mann-Whitney U가 적절.

### Q4. "SnowNLP는 전자상거래 리뷰로 학습되었는데, 문학 리뷰에 적합한가요?"
**A.** 한계 인정. 문학 도메인 샘플 200건에 대해 연구자 라벨링 후 SnowNLP 예측을 비교하여 정확도를 제시하고, 질적 코딩으로 보완.

### Q5. "카이제곱 검정에서 기댓값 5 미만 셀이 20% 이상일 경우는?"
**A.** Fisher의 정확검정으로 대체.

## 통계 검증 전체 요약

| 분석 목적 | 통계 방법 | 대안 |
|-----------|-----------|------|
| 특징어 빈도 차이 | 카이제곱 검정(χ²) | Fisher's exact test |
| 감성 점수 차이 | Mann-Whitney U | Welch's t-test (정규시) |
| 인물 언급 빈도 | 독립표본 t검정 | Mann-Whitney U |
| 토픽 분포 차이 | Jensen-Shannon Divergence | KL Divergence |
| 별점-감성 상관 | Spearman 상관계수 | Pearson (정규시) |
| 코더 간 신뢰도 | Cohen's Kappa | Krippendorff's α |

## 혼합연구설계(MMR) 적용 근거

Creswell & Plano Clark(2018)의 **수렴적 평행 설계(Convergent Parallel Design)** 채택:

```
양적 데이터                     질적 데이터
(텍스트마이닝 결과)       ↔    (질적 코딩 결과)
                    ↓
              동시 수집, 개별 분석
                    ↓
              결과 통합 해석
                    ↓
        양적-질적 결과의 수렴/발산 논의
```

### 채택 이유
1. 텍스트마이닝이 발견한 패턴(양적)과 독자의 실제 해석 프레임(질적)을 상호 검증
2. 양적 결과만으로는 포착 불가능한 문화적·텍스트언어학적 의미를 질적 분석으로 보완
3. 박사논문의 이론적 깊이와 재현성을 동시에 확보

## 5. 한국 독자 데이터의 지위 = "해석적 참조"

**결정 근거**: 방향성 결정 로그 D1 (2026-09-03)

### 원칙
한국 Yes24 독자 데이터는 **원천어(source language) 독자 반응의 해석 좌표축**으로 활용하며,
중국 독자 데이터와의 직접 통계 비교는 수행하지 않는다.

### 금지 사항
- ❌ 한국 vs 중국 t-test, χ², Mann-Whitney 등 직접 통계 검증
- ❌ "한국 독자가 X점 더 긍정적" 식의 정량 비교 서술
- ❌ 언어권별 감성사전 스케일 차이를 무시한 점수 비교

### 허용·권장 사항
- ✅ 한국 데이터도 정량·정성 분석 수행 (동일 방법론)
- ✅ 결과는 각 챕터 소결에서 **참조 정보**로 제시
- ✅ 대조 서술 예: "원천어 독자는 X 장면을 신체적 저항으로 수용하는데, 중국어 번역본 독자는 이를 Y로 해석한다"

### 방법론적 근거
언어 간 감성사전·형태소 분석기·문화적 코드가 이질적이므로 직접 통계 비교의 타당성이 낮으며,
한국 독자 반응은 원작의 수용 지형을 파악하기 위한 **참조 baseline** 역할이 적합함.

## 6. 텍스톰(TEXTOM)의 지위 = "검증 도구"

**결정 근거**: 방향성 결정 로그 D2 (2026-09-03)

### 원칙

상용 텍스트 분석 도구인 텍스톰(TEXTOM)은 **핵심 결과의 교차 검증용**으로 사용한다.

| 도구 | 위치 | 사용 범위 |
|------|------|-----------|
| Python 파이프라인 (본 저장소 `code/`) | 주 도구 | 전체 분석 (전처리·TF-IDF·LDA·감성·네트워크·통계) |

### 텍스톰 사용 범위 (정확히 이 항목만)
1. 각 번역본 TF-IDF **상위 20개 주제어** 대조
2. 인물 공출현 네트워크의 **주요 군집 구조** 대조

### 채택 근거

### 방법론 챕터 서술 샘플
> 본 연구의 주 분석 도구는 Python 기반 자체 구축 파이프라인이며(부록 2 코드 및 GitHub 저장소 참조), 결과의 외적 타당성 확보를 위해 상용 텍스트 분석 도구인 텍스톰(TEXTOM)으로 핵심 결과 항목(주제어 상위 20개, 인물 네트워크 주요 군집)에 대해 교차 검증을 수행하였다.

## 7. Nobel 수상 효과의 시기 분리 처리

**결정 근거**: 방향성 결정 로그 D3 (2026-09-03)

### 원칙
2024년 10월 10일(한강 노벨문학상 수상일)을 기준으로 리뷰 코퍼스를 두 시기로 분리하여 처리한다.
메인 분석은 Nobel 이전 코퍼스를 대상으로 수행하며,
Nobel 이후 코퍼스는 이벤트 효과 관찰을 위한 보완 분석으로 활용한다.

### 왜 분리인가

Nobel 수상은 독자 유입 규모와 리뷰 성격을 근본적으로 변화시키는 **외생 사건(exogenous event)**이다.
번역가의 텍스트 개입이 독자 수용에 미치는 순수 효과를 관찰하기 위해서는 시기 통제가 불가결하다.

| Nobel 이전 | Nobel 이후 |
|-----------|-----------|
| 조용한 문학 애독자 | 뉴스 유입 대중 |
| 실제 독서 후 감상 | 미독서 축하글 포함 |
| 텍스트 자체에 집중 | 작가·이벤트에 집중 |
| 부정 리뷰 정상 분포 | 긍정 압도 |

### 왜 배제(exclude)가 아닌 분리(separate)인가

- **배제 문제**: 후추통 2021(현행 유통본) 데이터 급감 → 연구 2·3 부실화
- **분리 이점**:
  - 메인은 순수 번역 효과 관찰
  - 보완 분석에서 이벤트 효과 자체를 부가 논점화
  - 심사 방어: "노벨 효과 통제했는가?" → "분리 처리했고 각각 보고"

### 실무 처리

두 크롤러 모두 `is_post_nobel` 컬럼(bool)을 자동 생성:
- `crawler_douban/crawl.py`: `parse_comments()` → `is_post_nobel(date)` 호출
- `crawler_yes24/crawl.py`: 이미 구현됨

분석 코드에서:
```python
df_pre = df[df["is_post_nobel"] == False]   # 메인 분석
df_post = df[df["is_post_nobel"] == True]   # 보완 분석
```

### 각 번역본별 영향도 예상

| 번역본 | Nobel 이전 예상 비중 | 실제 상황 |
|--------|---------------------|-----------|
| 천일 2013 (본토, 절판) | ~90%+ | 2023 절판 이후 자연 감소 |
| 천일 2016 (타이완, 번체) | ~70% | 대만·홍콩 독자 중심 |
| 후추통 2021 (본토) | ~30~40% | 노벨 이후 유입 집중 |
| Yes24 (한국) | ~30% | 국뽕성 유입 심함 |

### 방법론 챕터 서술 샘플
> 본 연구의 데이터는 2024년 10월 10일(한강 노벨문학상 수상일)을 기준으로 두 시기 코퍼스로 분리하여 처리한다. 노벨상 수상은 독자 유입 규모와 리뷰 성격을 근본적으로 변화시키는 외생 사건이므로, 번역가의 텍스트 개입이 독자 수용에 미치는 순수 효과를 관찰하기 위해서는 시기 통제가 불가결하다. 본 논문의 메인 분석은 노벨 이전 코퍼스(N=x)를 기반으로 수행하며, 노벨 이후 코퍼스(N=y)는 이벤트 효과의 관찰과 논의를 위한 보완 분석 자료로 활용한다. 이 시기 분리 처리는 한국·중국 양쪽 코퍼스에 동일하게 적용된다.
