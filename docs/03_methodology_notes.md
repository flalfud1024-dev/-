# 방법론 상세 노트

## 바이브 코딩 vs 논문용 파이프라인

| 구분 | 바이브 코딩 | 논문용 파이프라인 |
|------|-------------|-------------------|
| 목적 | 빠른 결과 | 재현 가능한 분석 |
| 코드 이해 | 불필요 | 필수 (심사 질문 대비) |
| 랜덤 시드 | 미설정 | 고정 필수 (random_state=42) |
| 버전 관리 | 없음 | requirements.txt 명시 |
| 논문 부록 | 해당 없음 | 전체 코드 첨부 |
| 재현성 | 불가 | 타 연구자 동일 결과 도출 가능 |

**결론**: 바이브 코딩으로 아이디어를 탐색하고, 그 결과를 **재현 가능한 코드로 정제**하는 것이 박사논문의 올바른 접근.

## 재현성 확보를 위한 필수 서술 항목

논문 방법론 챕터에 **반드시** 서술:

1. **분석 환경**: Python 3.10.x, 패키지 버전 전체 명시
2. **랜덤 시드**: 전 분석 `RANDOM_SEED = 42` 고정
3. **전처리 기준**: 최소 토큰 수 10개 미만 리뷰 제외 (근거 서술)
4. **LDA 토픽 수 결정**: 코히런스 스코어 c_v 기준
5. **코드 전문**: 부록 2에 첨부
6. **데이터**: 부록 5에 수집 현황 명시 (익명화 처리, 더우반 이용약관 준수 여부)

## 예상 심사 질문 대응 노트

심사위원이 물을 수 있는 질문 + 대응 방향:

### Q1. "LDA에서 토픽 수를 왜 이 숫자로 결정하셨나요?"
**A.** 코히런스 스코어(c_v)를 k=3~8 구간에서 계산하여 최대값을 선택. c_v는 인간 평가자와의 상관관계가 가장 높은 지표로 알려져 있음(Röder et al., 2015).

### Q2. "c_v 말고 다른 지표는 왜 안 쓰셨나요?"
**A.** u_mass, c_uci, c_npmi도 검토했으나 c_v가 단어 공출현 창(sliding window)과 NPMI 기반으로 인간 해석과의 정합성이 높아 채택.

### Q3. "Mann-Whitney U를 쓴 이유가 뭔가요? t-검정은 왜 안 되나요?"
**A.** Shapiro-Wilk 정규성 검정 결과 감성 점수가 정규분포를 따르지 않음(p < 0.05). 따라서 비모수 검정인 Mann-Whitney U가 적절.

### Q4. "SnowNLP는 전자상거래 리뷰로 학습되었는데, 문학 리뷰에 적합한가요?"
**A.** 한계 인정. 문학 도메인 샘플 200건에 대해 연구자 라벨링 후 SnowNLP 예측을 비교하여 정확도를 제시하고, 질적 코딩으로 보완.

### Q5. "카이제곱 검정에서 기댓값 5 미만 셀이 20% 이상일 경우는?"
**A.** Fisher의 정확검정으로 대체.

## 통계 검증 전체 요약

| 분석 목적 | 통계 방법 | 대안 |
|-----------|-----------|------|
| 특징어 빈도 차이 | 카이제곱 검정(χ²) | Fisher's exact test |
| 감성 점수 차이 | Mann-Whitney U | Welch's t-test (정규시) |
| 인물 언급 빈도 | 독립표본 t검정 | Mann-Whitney U |
| 토픽 분포 차이 | Jensen-Shannon Divergence | KL Divergence |
| 별점-감성 상관 | Spearman 상관계수 | Pearson (정규시) |
| 코더 간 신뢰도 | Cohen's Kappa | Krippendorff's α |

## 혼합연구설계(MMR) 적용 근거

Creswell & Plano Clark(2018)의 **수렴적 평행 설계(Convergent Parallel Design)** 채택:

```
양적 데이터                     질적 데이터
(텍스트마이닝 결과)       ↔    (질적 코딩 결과)
                    ↓
              동시 수집, 개별 분석
                    ↓
              결과 통합 해석
                    ↓
        양적-질적 결과의 수렴/발산 논의
```

### 채택 이유
1. 텍스트마이닝이 발견한 패턴(양적)과 독자의 실제 해석 프레임(질적)을 상호 검증
2. 양적 결과만으로는 포착 불가능한 문화적·텍스트언어학적 의미를 질적 분석으로 보완
3. 박사논문의 이론적 깊이와 재현성을 동시에 확보
