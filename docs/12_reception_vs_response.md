## 두 이론의 근본 차이

| 축 | 독자반응 (Rosenblatt) | 독자수용 (Iser) |
|----|----------------------|-----------------|
| 학파 | 미국 실용주의 (1938~) | 독일 콘스탄츠 학파 (1974~) |
| 함께 언급 | Stanley Fish, Bleich | Jauss, Ingarden |

| 시간성 | 개별 독서의 순간 | 역사적 수용 지평 |
| 대표 개념 | Transaction | Leerstellen, Konkretisation |

## 왜 독자수용(Iser)이 이 논문에 맞는가

### 1. 이론 생태계의 정합성 ⭐ (결정적)
지금까지 채택한 이론들이 모두 유럽 대륙 전통:
- Beaugrande & Dressler 텍스트언어학 (독일)
- Genette 파라텍스트 (프랑스)
- Bakhtin 도피구 (러시아)
- Barthes 저자의 죽음 (프랑스)
- Benjamin 번역가의 과제 (독일)

**Iser(콘스탄츠 학파) 추가 → 이론 생태계 한 흐름 정렬**.
Rosenblatt(미국 실용주의)는 이질.

### 2. MRQ와의 정합성
MRQ: "텍스트-언어학적 개입이 독자의 인물·주제 수용을 어떻게 **구조적으로 변형**하는가"

**"구조적 변형"** = Iser의 함축 독자·빈자리 구조 관점.
Rosenblatt에서는 "구조"가 아니라 "개별 만남"이 중심.

### 3. 번역학 전통과의 접점
번역학은 오래전부터 수용미학과 협업:
- Toury의 번역규범 (수용 문화 지평)
- Even-Zohar의 다체계이론
- 번역본 수용의 역사적 지평 (Jauss 기대지평)

Rosenblatt는 문학 교육 전통 → 번역학과 접점 약함.

### 4. 텍스트마이닝 데이터와의 호환
- Rosenblatt = 개별 독자의 미학적 경험 (텍스트마이닝으로 포착 어려움)
- Iser = 집합적 수용 패턴 (텍스트마이닝 aggregate 성격과 정합)

### 5. 한국 통번역학 학계 관행
독자수용 계열이 훨씬 자주 인용됨. 심사위원 즉각 인식.

### 6. Ch 7 철학 챕터와의 접속
- Iser의 함축 독자 ↔ Barthes의 텍스트 앞의 독자
- Iser의 빈자리 채우기 ↔ Benjamin의 원전의 여생
- Rosenblatt로는 Ch 7 논의가 얕아짐

## Rosenblatt의 부분 통합

주 이론 프레임은 Iser로 통일하되, Rosenblatt의 개념 도구는 필요 시 부분 활용.

```
【주 이론 프레임】 독자수용 (Iser + Jauss)
   ▸ 논문 전체 이론적 골격
   ▸ MRQ·SRQ의 이론 언어
   ▸ Ch 2 이론 챕터의 중심 축
   ▸ Ch 7 철학 챕터의 접속점
        │
        ↓ 보조 활용
【보조 어휘】 독자반응 (Rosenblatt)
   ▸ 미학적 읽기 vs 효과적 읽기 구분
   ▸ 특정 정성 분석 순간의 개별 독자 transaction 논의
   ▸ Ch 4·5·6 질적 코딩 세부에서 부분 인용
```

### 새 개념 도구가 열림

| Iser 개념 | 논문에서의 조작화 |
|-----------|-------------------|
| 함축 독자 (implied reader) | 번역가가 상정한 독자 프로파일 (파라텍스트 분석) |
| 빈자리 (Leerstellen) | 원전-번역본 대조에서 발생한 의미 공백 |
| 구체화 (Konkretisation) | 독자 리뷰에서 이 공백이 채워지는 방식 |
| 기대지평 (Erwartungshorizont, Jauss) | 한·중 문화권별 사전 기대 (한국 baseline 참조) |

### D5 (제목 케이스)와의 정합
**-主義의 소거 = Iser의 언어로 "의도된 빈자리의 봉인"**

Iser 개념이 D5를 이론적으로 정확히 기술.
