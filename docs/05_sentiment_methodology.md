## 1. 분석 설계: 3-Layer 접근

SnowNLP 단일 사용의 도메인 부적합성 문제(전자상거래 리뷰 학습 모델)를 극복하기 위해 **3-layer 삼각검증(triangulation)** 적용.

```
┌─────────────────────────────────────────────────┐
│  Layer 1: 극성(Polarity)                          │
│    ① SnowNLP (ML 기반 baseline)                   │
│    ② 사전 기반 점수 (투명성·재현성 확보)            │
│    → 두 지표 상관계수로 내적 일관성 검증             │
├─────────────────────────────────────────────────┤
│  Layer 2: 강도(Intensity) — 극성 넘어선 차원       │
│    ① 강조어 비율 (정도부사 빈도)                    │
│    ② 감정어 밀도 (텍스트 단위당 감정어)             │
│    ③ 문장부호 강도 (느낌표 누적 등)                 │
│    → 합성 지표(composite intensity)               │
├─────────────────────────────────────────────────┤
│  Layer 3: 감정 범주(Ekman 6-emotion)              │
│    기쁨/슬픔/분노/공포/혐오/놀람                    │
│    → 번역본별 지배적 감정 프로파일                   │
└─────────────────────────────────────────────────┘
```

**논문 기여**: 단순 긍/부정 극성만 보고하는 기존 중국어 텍스트마이닝 연구 관행을 넘어서, 강도·감정범주를 포함한 **다차원 감성 프로파일**을 제시.

## 2. 감성사전 선택의 근거

### 파일럿 vs 본 분석

| 단계 | 사전 | 규모 | 용도 |
|------|------|------|------|
| 파일럿 | 논문 내장 최소 사전 | ~50어 | 파이프라인 검증 |
| 본 분석 | **DUTIR(大连理工) 情感本体库** | 27,466어 | 논문 최종 결과 |
| 대안 | BosonNLP 감성사전 | 114,767어 | 리뷰 도메인 특화 |

### 권장 조합
1. **DUTIR**: 감정 범주(Ekman/Plutchik) 대응 가능 → Layer 3에 최적
2. **BosonNLP**: 웹 리뷰 학습 → Layer 1 사전 기반에 적합
3. 두 사전의 교집합 어휘 → 고신뢰도 핵심 감성어로 선정

### 논문 서술 포인트
> "본 연구는 범용 감성사전과 문학 텍스트의 도메인 괴리를 인지하며, 파일럿 단계에서 무작위 표본 200건에 대한 연구자 수동 라벨링을 수행하여 사전의 도메인 적합성을 검증하였다(04b_sentiment_validation.py)."

## 3. 검증 프로토콜

### 3.1 수동 코딩 표본

- 번역본별 **층화 무작위 표본** 70건 × 3 = 210건 (랜덤시드 42)
- 코더: 연구자 본인(Coder A) + 제2코더(Coder B, 지도교수 또는 동료)

### 3.2 코딩 기준

| 필드 | 값 | 설명 |
|------|----|----|
| `manual_polarity` | -1/0/1 | 부정/중립/긍정 |
| `manual_intensity` | 1/2/3 | 약/중/강 |
| `manual_emotion` | joy/sadness/anger/fear/disgust/surprise/neutral | Ekman 6 + 중립 |
| `notes` | 자유 서술 | 텍스트언어학적 근거 |

### 3.3 신뢰도 지표

| 지표 | 수용 기준 | 근거 |
|------|-----------|------|
| Cohen's Kappa (A vs B) | ≥ 0.80 | Landis & Koch(1977) "almost perfect" |
| SnowNLP vs Manual (accuracy) | ≥ 0.70 | 문학 도메인 일반 기준 |
| Pearson r (lexicon vs manual) | ≥ 0.60 | 연속값 타당도 |

**미달 시 대응**:
- Kappa < 0.8 → 불일치 항목 토론 후 재코딩
- SnowNLP 정확도 < 0.7 → 사전 기반 지표를 주요 지표로 승격
- 논문에 한계로 명시 후 질적 코딩 비중 확대

## 4. 통계 검증 결정 트리

```
감성 점수 N ≥ 30
      │
      ▼
Shapiro-Wilk 정규성 검정
      │
   ┌──┴──┐
   정규    비정규
   │       │
   ▼       ▼
2군: Welch t-test      Mann-Whitney U
3군: One-way ANOVA     Kruskal-Wallis H
   │       │
   └──┬────┘
      ▼
p < .05?
      │
   ┌──┴──┐
   예    아니오
   │     → 귀무가설 채택
   ▼
Post-hoc pairwise
(Bonferroni 보정)
      │
      ▼
효과크기 보고
(Cohen's d / rank-biserial r)
      │
      ▼
부트스트랩 95% CI (N=10,000)
```

### 왜 이 구조인가
- **Shapiro-Wilk**: 리뷰 점수는 대체로 비정규(우편향) → 파일럿에서 확인
- **Welch vs Student t**: 번역본별 표본 크기 불균형 예상 → Welch 채택
- **Bonferroni**: 3쌍 동시 비교 → 1종 오류 확률 통제
- **효과크기**: p값만으로는 실질적 차이 판단 불가 → APA 7판 필수
- **부트스트랩 CI**: 비모수 상황에서도 평균차 불확실성 정량화

## 5. 연구별 감성분석 적용 매핑

### 연구 1: 섹슈얼리티 하이재킹 (천일2013 vs 타이완2016)
- **핵심 지표**: 극성 + Ekman `disgust`/`fear`/`surprise`
- **가설**: 성적 장면 복원(2016)이 감정 강도를 증폭시키며 `surprise/disgust` 비중 증가
- **검증**: Mann-Whitney U + 효과크기

### 연구 2: 정신질환 프레이밍 (천일2013 vs 후추통2021)
- **핵심 지표**: 극성 + Ekman `fear`/`disgust` (낙인의 정서적 잔재)
- **가설**: '정신질환자' 표제어가 독자 리뷰에 부정적 극성과 `fear/disgust` 편향을 유도
- **검증**: Mann-Whitney U + `정신병` 계열 어휘 빈도와 감성 점수 간 Spearman 상관

### 연구 3: 전면 비교 (후추통2021 vs 타이완2016)
- **핵심 지표**: 3-layer 전체 + 인물별 감성
- **가설**: 지역·번역자 차이가 주제 감정 프로파일의 구조적 차이를 만듦
- **검증**: 3군 Kruskal-Wallis → pairwise + 인물별 박스플롯

## 7. 논문 방법론 챕터 서술 샘플 (3.3.4 절)

> 본 연구는 독자 리뷰의 감성 구조를 극성·강도·감정범주의 세 층위로 분석한다. 극성은 기계학습 기반 SnowNLP와 DUTIR(大连理工大学情感本体库) 기반 사전 점수를 병렬로 산출하여 삼각검증한다. 강도는 정도부사 비율, 감정어 밀도, 문장부호 누적 강도의 세 지표를 가중합한 합성 지표(composite intensity)로 조작화한다. 감정범주는 Ekman(1992)의 6대 기본감정을 기준으로 한다. 자동 분석의 도메인 적합성은 번역본별 층화 무작위 표본 70건(총 210건)에 대한 이중 코딩(Cohen's Kappa ≥ .80) 결과와 비교하여 검증한다. 집단 간 차이는 Shapiro-Wilk 정규성 검정 후 적절한 검정법을 선택하며, 3군 비교의 경우 Bonferroni 보정된 사후검정과 효과크기(rank-biserial r 또는 Cohen's d)를 함께 보고한다. 모든 통계 산출은 부트스트랩 95% 신뢰구간(N=10,000, random_state=42)을 수반한다.
