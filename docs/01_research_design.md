## 연구 1: 섹슈얼리티 하이재킹과 독자반응

### 이론 프레임

**"섹슈얼리티 하이재킹(Sexuality Hijacking)"** — 이 개념을 논문에서 직접 정의하는 것이 독창성의 핵심.

**추천 이론 조합:**
- **검열이론**: Bourdieu의 문학장(Literary Field) — 출판권력이 텍스트에 개입하는 방식
- **화용론**: Grice의 협력원칙 — 삭제로 인한 함축(implicature) 변화
- **수용미학**: Jauss의 기대지평(Horizon of Expectations) — 독자가 구성하는 의미의 차이
- **텍스트언어학**: 응결성(cohesion)/응집성(coherence) 파괴 — 삭제가 서사 구조에 미치는 영향

### 분석 설계

```
[텍스트 분석]
원본(한국어) → 천일2013(삭제본) → 타이완2016(복원본)
         ↓
삭제된 장면 목록화 + 삭제 전후 서사 응결성 변화 분석
(텍스트언어학: 지시, 대용, 접속, 어휘적 응결 장치)

         ↓

[독자반응 분석]
豆瓣 천일2013 리뷰 vs 타이완 플랫폼 리뷰
- 성적 장면 관련 어휘 언급 빈도
- '몸/신체' 관련 토픽 클러스터 비교
- 영혜 인물 해석 방향성 (피해자 vs 저항자)
```

### 핵심 연구 질문

> 성적 장면의 검열적 삭제는 독자로 하여금 영혜의 신체적 저항을 어떻게 다르게 해석하게 만드는가?

### 예상 가설

- **천일2013 독자** → 영혜를 정신적 이탈자로 해석 (신체 서사 부재)
- **타이완2016 독자** → 영혜를 신체적 저항 주체로 해석 (성적 장면 = 저항의 언어)

## 연구 2: 출판 프레이밍과 표제어의 이데올로기

### 이론 프레임

이 연구는 **비판적 담론분석(CDA)**이 핵심.

- **Genette의 파라텍스트(Paratext) 이론** ← 가장 중요
  - 표제어, 표지, 서문은 독자의 독서 프레임을 사전 설정함
  - 번역본의 파라텍스트 = 번역자/출판사의 이데올로기적 개입 증거
- **Fairclough의 CDA** — 언어와 권력 관계
- **Labeling Theory(낙인이론)** — '정신질환자' 규정의 사회적 효과

### 분석 설계

```
[표제어 텍스트 분석]
천일2013 표제어: "정신질환자 영혜의..."
         ↓
1. 어휘 선택 분석: '정신질환' 프레임이 활성화하는 인지 스키마(schema)
2. 명제 구조 분석: 영혜를 능동 주체 vs 수동 객체로 구성하는 방식
3. 후추통2021 표제어와 어휘/통사 대조

[독자반응 연계]
→ 표제어의 '정신질환' 프레이밍이 豆瓣 리뷰에서
  영혜 묘사 어휘에 얼마나 침투해 있는가?

측정 방법:
- '精神病/精神疾病/疯了' 등 정신질환 관련어 빈도
- 천일2013 리뷰 vs 후추통2021 리뷰 비교
- 카이제곱 검정으로 통계적 유의미성 검증
```

### 핵심 연구 질문

> 출판사의 표제어가 '정신질환자'로 영혜를 규정할 때, 독자들은 이 프레임을 내면화하여 리뷰에서 재생산하는가?

## 연구 3: 후추통2021 vs 타이완2016 전면 비교

### 분석 층위 전체 설계

```
층위 1: 파라텍스트 비교
        표지 디자인 기호학 + 표제어 CDA

층위 2: 양적 텍스트마이닝 (豆瓣 리뷰)
        ① 주제어 빈도 (TF-IDF)
        ② LDA 토픽모델링
        ③ 감성분석
        ④ 인물 공출현 네트워크

층위 3: 질적 코딩
        ① 연역적 코딩 (이론 기반)
        ② 귀납적 코딩 (데이터 기반)
        ③ 코더 간 신뢰도 (Cohen's Kappa)
```

### 층위 1: 표지 기호학 분석

**Barthes의 기호학 적용:**
- **외시(Denotation)**: 표지에 실제로 무엇이 있는가
- **함의(Connotation)**: 그것이 내포하는 문화적 의미
- **신화(Myth)**: 표지가 자연화하는 이데올로기

**분석 항목:**
- 색채 기호
- 신체 이미지 유무: 영혜의 신체 표상 방식
- 식물/음식 이미지: 채식의 의미화 방식
- 타이포그래피: 제목 글꼴이 주는 장르적 신호

### 층위 2: 양적 텍스트마이닝 상세 설계

**① TF-IDF + 워드클라우드**
- 예상: 후추통2021 → '女性/身体/自由/抵抗'
- 예상: 타이완2016 → '暴力/家庭/欲望/植物'

**② LDA 토픽모델링**
- 각 번역본에서 5-7개 토픽 추출
- 코히런스 스코어로 최적 토픽 수 결정
- pyLDAvis로 인터랙티브 시각화

**③ 감성분석 (3층위)**
- 감성 강도 분포
- 인물별 감성 (영혜/남편/형부)
- 별점과 감성 점수 상관관계

**④ 인물 공출현 네트워크**
- 노드: 주요 인물 / 엣지: 공출현 빈도
- 중심성 분석: 담론의 중심 인물

### 층위 3: 질적 코딩 체계

**연역적 코딩 (이론에서 도출)**

| 코드 범주 | 하위 코드 예시 |
|-----------|----------------|
| 인물 해석 프레임 | 피해자/저항자/이상자/예술가 |
| 주제 프레임 | 페미니즘/가족폭력/생태/실존 |
| 번역 평가 | 문체언급/오역지적/번역자언급 |
| 신체 담론 | 섹슈얼리티/채식/식물화/폭력 |

**귀납적 코딩 (데이터에서 발견)**
- 오픈 코딩 → 축 코딩 → 선택 코딩 (근거이론 방식)
- 예상치 못한 담론 패턴 발견 가능

**신뢰도 검증**
- Cohen's Kappa ≥ 0.8 목표
- 연구자 본인 + 제2코더 (지도교수 또는 동료)

## 통계 검증 방법 요약

| 분석 목적 | 통계 방법 |
|-----------|-----------|
| 특징어 빈도 차이 | 카이제곱 검정(χ²) |
| 감성 점수 차이 | Mann-Whitney U 검정 |
| 인물 언급 빈도 | 독립표본 t검정 |
| 토픽 분포 차이 | Jensen-Shannon Divergence |
| 별점-감성 상관 | Spearman 상관계수 |
