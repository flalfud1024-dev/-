## 🌟 MRQ (Main Research Question)

> **한강 『채식주의자』의 세 중국어 번역본에 나타난 텍스트-언어학적 개입은 독자의 인물·주제 수용을 어떻게 구조적으로 변형하며, 이 관계는 Beaugrande & Dressler의 텍스트성 기준(의도성·용인성·상호텍스트성·응집성)으로 어떻게 해석되는가?**

### MRQ 설계 근거
- 상위 논지("번역=이데올로기적 개입") 정합
- 텍스트성 이론을 표면에 명시 → 독창성 지점
- "구조적으로 변형" → 텍스트마이닝으로 관찰 가능한 것 시사
- 세 번역본을 하나의 그림에 통합

---

## 📖 SRQ1 (연구 1 / Ch 4) — 섹슈얼리티 하이재킹

> **천일 2013(본토·성적 장면 삭제)과 천일 2016(타이완·성적 장면 복원)의 응결성·응집성 차이는 독자의 영혜 인물 해석에 어떤 차이를 만드는가?**

| 층위 | 답하는 방법 |
|------|-------------|
| 이론 | 응결성·응집성 (Beaugrande) + 화용론 함축(Grice) + 검열이론(Bourdieu) |
| 데이터 | 두 번역본 원문 대조 + 더우반 리뷰 (Nobel 이전 코퍼스) |
| 정량 | TF-IDF 신체·섹슈얼리티 어휘 빈도, 감성 극성 |
| 정성 | 영혜 해석 프레임 코딩 (피해자 vs 저항 주체) |
| 참조 | 한국 독자의 성적 장면 수용 방식 |

**독창성**: '섹슈얼리티 하이재킹(Sexuality Hijacking)' 개념 제안.

---

## 📖 SRQ2 (연구 2 / Ch 5) — 출판 프레이밍과 낙인

> **천일 2013의 표제어 "정신질환자로서의 관능의 세계"라는 파라텍스트적 프레이밍(의도성)은 후추통 2021의 대안적 프레이밍과 대비하여 독자의 영혜 인물 낙인화에 어떻게 침투하는가?**

| 층위 | 답하는 방법 |
|------|-------------|
| 이론 | Genette 파라텍스트 + Barthes 기호학 + 낙인이론 + CDA(Fairclough) |
| 데이터 | 두 번역본 표제어/표지 + 더우반 리뷰 (Nobel 이전) |
| 정량 | 정신질환 관련 어휘 빈도, 카이제곱 검정 |
| 정성 | 인물 프레임 코딩 (병리적 vs 저항 주체) |
| 참조 | 한국 독자의 영혜 프레이밍 (병리화 여부) |

**독창성**: 표제어의 이데올로기적 프레이밍이 독자 담론에 침투하는 정도의 계량화.

---

## 📖 SRQ3 (연구 3 / Ch 6) — 전면 비교

> **후추통 2021과 천일 2016의 총체적 번역 차이(텍스트성 4기준 통합)는 독자의 주제 해석 지형(가부장제/페미니즘/생태/실존)과 인물 담론 중심축을 어떻게 재구성하는가?**

| 층위 | 답하는 방법 |
|------|-------------|
| 이론 | 텍스트성 4기준 통합 + Bakhtin 도피구 + 예술적 번역(Lotman) |
| 데이터 | 두 번역본 전체 + 표지·표제어 + 더우반 리뷰 (Nobel 이전) |
| 정량 | LDA 토픽 모델링, 인물 공출현 네트워크 |
| 정성 | 주제 프레임 코딩(연역+귀납), 예술적 번역 순간 클로즈리딩 |
| 참조 | 한국 독자의 주제 해석 지형과 인물 중심축 |

**독창성**: 파일럿에서 발견한 인물 중심축 이동(형부→전남편)의 이론적 설명 완성.

## 📊 프로포절 원안 vs 개선안

| 항목 | 프로포절 원안 (2025) | 개선안 (2026.9) |
|------|---------------------|-----------------|
| 구조 | 평면적 3개 RQ | 위계적 1 MRQ + 3 SRQ |
| 이론 통합 | 개별 언급 | MRQ에 텍스트성 명시 |
| 조작화 | "예술적 번역 차이" 모호 | 각 SRQ에 지표 명시 |
| 번역본 명시 | 두 중국어 (모호) | 3-쌍 명시 |
| 한국 baseline | 미언급 | 각 SRQ의 참조 좌표축 |
| Nobel 통제 | 미언급 | 방법론에서 코퍼스 분리 |
| 챕터 대응 | 애매 | Ch 4·5·6 1:1 |
| 독창성 | 방법론 위주 | 개념 기여 + 방법론 |

---

## 💡 개선안의 강화 지점

1. **논리 계통 확립**: MRQ 상위, SRQ 하위. 프로포절은 병렬.
2. **조작화 완성**: 각 SRQ에 "무엇을 어떻게 측정할지" 매핑.
3. **이론+방법 결합**: 각 SRQ에 이론+정량+정성이 통합 배치.
4. **독창성 명시**: 개념 기여(섹슈얼리티 하이재킹, 파라텍스트 침투) 표면화.
5. **결정 흡수**: 한국 baseline(D1), 텍스톰(D2), Nobel 분리(D3)가 방법론으로 자연 흡수.

## 🎯 이 RQ 세트로 답할 수 있는 것

- 번역 개입이 독자 수용을 어떻게 변형하는가 ✅
- 어떤 텍스트-언어학적 층위에서 변형이 일어나는가 ✅
- 문화적·이데올로기적 맥락과 어떻게 연동되는가 ✅
- 정량 분석이 정성 분석과 어떻게 상호 검증되는가 ✅

## ⚠️ 이 RQ 세트로 답할 수 없는 것 (한계로 명시)

- 개별 독자의 심리적 수용 과정 (실험 연구 필요)
- 원작자 한강의 의도 (인터뷰·저자 자료 필요)
- Nobel 이후 수용 지형의 완전한 지도 (별도 연구 필요, 본 연구는 배제·보완)
