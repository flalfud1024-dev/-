## 🎯 북극성 (One-Sentence Thesis)

> **번역의 개입은 텍스트-언어학적 선택이며, 이는 독자 반응에서 텍스트-마이닝으로 관찰 가능하고, Beaugrande 텍스트성 7기준으로 해석 가능하다.**

앞으로 20개월 동안 모든 결정은 이 문장에 수렴시킬 것.

## 📊 5층 이론 아키텍처

```
【층위 5】 방법 (empirical)
  ▸ 텍스트 마이닝 (정량, 단평)
  ▸ 질적 코딩 (정성, 장평)
  ▸ Nida/Halliday/House 전체 텍스트 단위 분석
─────────────────────────────────────────
【층위 4】 파라텍스트 (framing)
  ▸ Genette 파라텍스트 (표제어·표지)
  ▸ Barthes 기호학 (외시/함의/신화)
─────────────────────────────────────────
【층위 3】 매개 (mediation) — 번역가의 개입 ★핵심
  ▸ Beaugrande & Dressler 텍스트성 7기준
    → 본 논문 집중: 의도성 · 용인성 · 상호텍스트성 · (+응집성)
  ▸ Bakhtin "도피구" (번역가 응답 의무)
  ▸ Schleiermacher 이화/동화
  ▸ Benjamin 순수언어
─────────────────────────────────────────
【층위 2】 수용 (reception)
  ▸ Iser/Jauss 독자 반응, 기대지평
  ▸ 디지털 시대 온라인 독자 담론 (더우반·Yes24)
─────────────────────────────────────────
【층위 1】 존재론 (ontology)
  ▸ Beaugrande 문학 텍스트 = 통보적 발화체
  ▸ Lotman "예술적 번역" = 불확정성
```

**독창성 지점**: Beaugrande 7기준을 평가 기준이 아니라 **번역 개입이 발생하는 지점**으로 재정의.

### D1: 한국 baseline = 해석적 참조

**금지**:
- 한국 vs 중국 직접 통계 검증 (t-test, χ², Mann-Whitney)
- "한국 독자가 더/덜 긍정적이다" 식 정량 비교 서술

**허용·권장**:
- 원천어 독자 반응을 **해석 좌표축**으로 사용
- 각 챕터 소결에서 "한국 독자는 X를 주목하는데, 중국어 번역본 독자는 Y로 수용된다" 식 대조
- 한국 데이터도 정량·정성 분석은 수행하되, 결과는 **참조 정보**로 제시

### D2: 텍스톰 = 검증 도구

**주 도구**: Python 자체 파이프라인 (본 저장소 `code/*.py`)
- 이유: 오픈소스, 버전 고정(requirements.txt), GitHub commit hash로 재현성 증명

**검증 도구**: 텍스톰(TEXTOM)
- 사용 범위: **핵심 결과 항목 일부만**
  - 각 번역본 TF-IDF 상위 20개 주제어
  - 인물 네트워크 주요 군집 구조
- 목적: 상용 표준 도구와의 결과 일치 확인 → 외적 타당성 보강

### D3: Nobel 전후 = 분리 분석

**기준일**: 2024-10-10 (한강 노벨문학상 발표일)

**처리 방식**:
- 모든 리뷰에 `is_post_nobel` 컬럼 부여 (True/False)
- 메인 분석: `is_post_nobel == False` 코퍼스만 사용 (연구 1·2·3 통계 검증)
- 보완 분석: `is_post_nobel == True` 코퍼스 별도 관찰 (챕터 6 소결에 논의)

**적용 대상**: 한국(Yes24) + 중국(더우반) **양쪽 모두**
- 이유: Nobel 뉴스는 국경을 넘어 확산됨. 특히 후추통 2021(현행 본토 유통본)이 큰 영향
- 배제(exclude) 안 함 — 후추통 2021 데이터가 급감하여 연구 2·3 부실화 우려

**연구별 영향도** (참고):
| 번역본 | Nobel 이전 | Nobel 이후 | 실제 영향 |
|--------|-----------|-----------|-----------|
| 천일 2013 (본토, 절판) | 대부분 | 극소량 | 자연스레 조용 |
| 천일 2016 (타이완) | 대부분 | 소량 | 상대적으로 약함 |
| 후추통 2021 (본토) | 일부 | **대량** | 노벨 유입 집중 |
| Yes24 (한국) | 소량 | **대량** | 국뽕성 유입 심함 |

**엄밀성 이점**:
- 메인 결과가 순수 "번역 효과" 반영
- 심사 질문 "노벨상 효과 통제했는가?" → 완벽 대응
- Nobel 이후 데이터도 버리지 않고 부가 논점화
