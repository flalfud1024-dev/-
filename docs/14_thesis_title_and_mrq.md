**단점**: "원작의 독자수용" 표현 어색 + D1(한국=참조)과 미묘한 긴장.

- "원작" 개념은 MRQ의 "참조 좌표축"에서 처리

> ## — 텍스트-언어학적 개입과 인물·주제 해석의 변용 —

### 각 요소가 담는 것

**대주제**:
- "한강 『채식주의자』 중문 번역본의" — 연구 대상 명확
- "독자수용" — D6 (Iser) 결정 반영

**부제목**:
- "텍스트-언어학적 개입" — 논문 상위 논지 요약 (Beaugrande 프레임)
- "인물·주제 해석의 변용" — 원 부제목 정신 계승 + D6 "구조적 변형" 압축

## MRQ 최종안 (모든 결정 통합)

> **번역학·텍스트언어학·기호학·번역철학을 아우르는 다학제적 관점에서, 한강 『채식주의자』 세 중문 번역본에 나타난 텍스트-언어학적 개입은 원작 독자수용을 참조 좌표축으로 할 때 독자의 인물·주제 해석을 어떻게 구조적으로 변형하며, 문학 번역 수용론에 어떤 이론적·실천적 시사점을 갖는가?**

### 이 MRQ가 담는 것

| 요소 | 관련 결정 |
|------|-----------|
| 다학제 | D7 |
| 세 번역본 | 프로포절 원안 유지 |
| 텍스트-언어학적 개입 | 방법론 프레임 |
| 원작 참조 좌표축 | D1 + 원 부제목 정신 |
| 인물·주제 해석 | 원 부제목 정신 |
| 구조적 변형 | D6 Iser 언어 |
| 시사점 | SRQ4 예고 |

---

## SRQ에서의 인물·주제 확인

원 부제목의 "인물·주제 해석" 정신이 이미 SRQ에 내장되어 있음:

- SRQ1: 독자의 **영혜 인물 해석** ✅
- SRQ2: 독자의 **인물 낙인화** (정신질환자 vs 저항 주체) ✅
- SRQ3: 독자의 **주제 해석 지형과 인물 담론 중심축** ✅
- SRQ4: 위 셋의 철학적 종합 (인물·주제 → 존재론적 재해석) ✅

**즉, 원 부제목의 초점은 이미 SRQ에 완전 통합되어 있음**.
