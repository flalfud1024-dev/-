## 다학제적 MRQ (개편안)

> **번역학·텍스트언어학·기호학·번역철학을 아우르는 다학제적 관점에서, 한강 『채식주의자』 세 중문 번역본에 나타난 번역 개입은 독자수용을 어떻게 구조적으로 변형하며, 문학 번역 수용론에 어떤 이론적·실천적 시사점을 갖는가?**

**신호**: "다학제적 관점" + "구조적 변형" + "이론적·실천적 시사점"

## 4 SRQ 다학제 배치

### SRQ1 (Ch 4) — 텍스트언어학 주도
> **응결성·응집성의 텍스트언어학적 관점에서, 천일 2013(성적 장면 삭제)과 천일 2016(성적 장면 복원)의 개입은 독자의 영혜 인물 수용에 어떤 구조적 변형을 낳는가?**

| 학제 | 역할 |
|------|------|
| 텍스트언어학 ⭐ | 응결성·응집성 파괴의 실증 |
| 기호학 | 삭제 부위의 상징적 함의 |
| 번역학 | 검열 번역 규범의 개입 |
| 번역철학 | Ch 7 재해석 대상 |

### SRQ2 (Ch 5) — 기호학 주도
> **기호학적 관점에서, 천일 2013 표제어 "정신질환자로서의 관능의 세계"의 파라텍스트적 프레이밍(외시·함의·신화)은 후추통 2021의 대안적 프레이밍 대비 독자의 인물 낙인화에 어떻게 침투하는가?**

| 학제 | 역할 |
|------|------|
| 기호학 ⭐ | Barthes 외시/함의/신화 |
| 텍스트언어학 | 표제어 의도성 분석 |
| 번역학 | 출판 파라텍스트 규범 |
| 번역철학 | Ch 7 재해석 대상 |

### SRQ3 (Ch 6) — 번역학 주도
> **번역학적 관점에서, 후추통 2021과 천일 2016의 총체적 번역 규범 차이(어휘·통사·문체 선택의 지형)는 독자의 주제 해석 지형과 인물 담론 중심축을 어떻게 재구성하는가?**

| 학제 | 역할 |
|------|------|
| 번역학 ⭐ | Toury 규범 + 지역·출판문화 |
| 텍스트언어학 | 4기준 통합 분석 |
| 기호학 | 표지 비교 |
| 번역철학 | Ch 7 재해석 대상 |

**D5 (제목 케이스) 주 배치**: SRQ3 진입 절.

### SRQ4 (Ch 7) — 번역철학 주도
> **번역철학적 관점에서, 세 번역본에서 관찰된 번역-독자 관계는 Barthes의 「저자의 죽음」과 Benjamin의 「번역가의 과제」 사이 변증법적 종합으로 어떻게 해석되며, 이는 문학 번역 수용론에 어떤 이론적·실천적 시사점을 갖는가?**

| 학제 | 역할 |
|------|------|
| 번역철학 ⭐ | Barthes-Benjamin 변증법 |
| 텍스트언어학 | Ch 4·5·6 실증 결과 재사용 |
| 기호학 | 표지·표제어 재해석 |
| 번역학 | 수용론 이론화 |

   ▸ Barthes-Benjamin 변증법적 종합

【방법론적 시사점】
   ▸ 텍스트마이닝 + 질적 코딩 + 철학적 해석 3-layer 통합
   ▸ 재현 가능 코드 공개 (GitHub)
   ▸ Nobel 외생 사건 통제 방법

【실천적 시사점】
   ▸ 문학 번역가: 파라텍스트의 이념적 무게
   ▸ 출판사: 표제어·표지 선택의 수용 효과
   ▸ 편집자: 검열적 삭제의 서사적 파급

【정책적/문화적 시사점】
   ▸ 번역 검열 문제의 학문적 인식 지평
   ▸ 원작 노벨상 이후 번역본 재수용의 지형 변화
   ▸ 원천어(한국)-목표어(중국) 간 문화적 매개
