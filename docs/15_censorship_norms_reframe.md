## 주 이론: Toury 번역규범 + 검열 이론

### Toury (1995) Descriptive Translation Studies
- **예비 규범 (preliminary norms)**: 무엇을 번역할지, 무엇을 삭제할지 ← **본 연구 핵심**
- **초기 규범 (initial norms)**: 적절성(원전 지향) vs 수용성(문화 지향)
- **작동 규범 (operational norms)**: 매트릭스·언어적 선택

### 검열과 번역 계보
- **Ó Cuilleanáin (1999)**: 국가 검열과 문학 번역
- **Merkle (2010)**: 번역 검열의 유형학
- **Billiani (2007)**: Modes of Censorship in Translation

### 중국 검열 특수성
- 中华人民共和国出版管理条例
- '외설 콘텐츠' 규제 (특히 문학 번역)
- 본토(검열) vs 타이완(자유) 대비

## 보조 개념: 섹슈얼리티 하이재킹

**정의 (Ch 4 소결에서 도입)**:
> "본 연구는 성적 장면에 집중된 검열이 텍스트의 서사적 응집성을 파괴하고 독자 수용을 특정 방향으로 재구성하는 양상을 '섹슈얼리티 하이재킹(Sexuality Hijacking)'으로 명명한다. 이는 Toury의 예비 규범이 성 규범과 맞물릴 때의 하위 유형으로 이해될 수 있다."

**위치**:
- Ch 4 소결 또는 개념 확장 절에만
- Ch 7(철학적 종합)에서 재소환 가능
- 후속 연구에서 개념 심화

**장점**:
- 연구자 창의성 유지
- 주 이론 방어 부담 회피
- 후속 연구 확장 가능

## SRQ1 재정의

### 이전
> 응결성·응집성의 텍스트언어학적 관점에서, 천일 2013(성적 장면 삭제)과 천일 2016(성적 장면 복원)의 개입은 독자의 영혜 인물 수용에 어떤 구조적 변형을 낳는가?

### 신
> **번역규범과 검열의 번역학적 관점에서, 천일 2013(본토, 성적 장면 삭제)과 천일 2016(타이완, 성적 장면 복원)에서 관찰되는 예비 번역규범 차이는 응결성·응집성의 파괴/복원을 매개로 독자의 영혜 인물 해석을 어떻게 구조적으로 변형하는가?**

### 새 SRQ1의 층위

| 층 | 내용 |
|----|------|
| 주 이론 | Toury 예비 번역규범 + 검열 이론 |
| 데이터 | 원본-2013-2016 대조 + 더우반 리뷰 (Nobel 이전) |
| 매개 기제 | 응결성·응집성 파괴 (텍스트언어학 = 보조) |
| 관찰 대상 | 독자의 영혜 인물 해석 |
| 지역 대조 | 본토(검열) vs 타이완(자유) |
| 부가 개념 | 소결에서 '섹슈얼리티 하이재킹' 명명 |

## D7 학제 매핑 재정비

SRQ1 주 이론 이동에 따른 재조정. SRQ1과 SRQ3 모두 번역학이지만 하위 이론으로 차별화:

```
SRQ1 (Ch 4)  → 번역학 주도 (⭐ 예비 규범 / 검열)
                + 텍스트언어학 보조 (응결성 파괴 = 매개 기제)

SRQ2 (Ch 5)  → 기호학 주도 (⭐ 파라텍스트)

SRQ3 (Ch 6)  → 번역학 주도 (⭐ 초기·작동 규범 / 전면 비교)
                + 다체계이론(Even-Zohar), Munday 번역가 목소리

SRQ4 (Ch 7)  → 번역철학 주도 (⭐ Barthes-Benjamin)
```

**차별화 원리**: Toury 규범 3층 중 SRQ1은 **예비 규범**, SRQ3은 **초기·작동 규범**을 다룸.
→ 논문 전체가 Toury 규범 체계 전체를 시연하는 형국 (오히려 강화됨).

## 이 재정의가 논문에 주는 것

1. **방어력 강화** — 심사에서 번역학 정전 이론으로 즉답 가능
